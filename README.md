# 冰壶运行带智能巡检工作台

把壶底运行带的几十张重叠微距照片拼成整圈、展开成长带，抑制花岗岩黑白斑干扰，按反光与顺圆周方向的细划痕计算 36 段粗糙度曲线，给出砂纸号/遍数、崩口标记和历史对比。

纯前端 TypeScript + Vite 实现；拼接与粗糙度分析运行在 Web Worker，长带、圆环和曲线均使用 Canvas 绘制。无需后端。

## 快速开始

```bash
npm install
npm run dev
```

打开终端输出的 `http://127.0.0.1:5173/`，在“拍摄引导”页点击 **一键分析两套**。

生产构建：

```bash
npm run build
npm run preview
```

合成真值验证（Node 直接运行同一套纯 TS 核心算法）：

```bash
npm run validate:synthetic
```

浏览器端到端冒烟（需要本机 Edge/Chrome；会自动点击完整流程并检查四个 Canvas 页面）：

```bash
npm run build
npm run preview -- --port 4173
# 另一个终端：
npm run smoke:browser
```

## 四个页面

1. **拍摄引导**：40 张合成微距接触片、重叠/取景提示、顺转/倒转两套、曝光与虚焦标记，也支持导入实拍照片。
2. **环形拼接**：Worker 内做 4 倍降采样 NCC 配准、抛物线亚像素修正、首尾闭合、闭合差融合、曝光增益和对焦归一化；Canvas 极坐标绘制成环。
3. **运行带展开**：圆环展开为长带，叠加 36 段粗糙度色罩、段界、崩口和选中框；下方绘制整圈曲线；段卡片给出砂纸号、遍数和理由。
4. **磨损对比**：本次曲线 vs 上次报告、CW vs CCW 圆环配准曲线、逐段 delta、建议变化、不均匀段、崩口施工和 localStorage 报告归档。

## 合成真值数据

`src/synth/generate.ts` 确定性生成：

- 4000×240 的整圈花岗岩运行带，对应约 48 cm 周长；
- 36 个检查段，7 种磨损程度：釉化、磨平、偏光滑、理想均匀、偏糙、划痕、深划痕；
- 黑色云母、白色石英、灰色斑点和细颗粒花岗岩纹理；
- 抛光区域的平滑强反光/镜面高光；
- 与粗糙度相关的圆周向细划痕和 row-correlated abrasive grain；
- 边缘崩口真值（默认 4 处，随机验证 3–6 处）；
- 40 张 CW 和 40 张 CCW 重叠照片，每张有独立曝光增益、传感器噪声和 0–2 次盒式模糊。

默认随机种子为 `20261126`，可重复生成同一套演示数据。

## 粗糙度算法如何避免把花岗岩纹理当成磨损

核心在 `src/core/analysis.ts`：

- **方向选择性**：圆周划痕在垂直于划痕方向的 Sobel 梯度上占优；各向同性的黑白斑同时产生横向和纵向梯度，方向比接近零。
- **暗槽中心检验 + 水平连续性**：只保留中心比上下 2 px 更暗、且 15 px 窗口内有足够连续响应的槽线，排除石英边缘和亮反光条边缘。
- **行均值能量**：先对整段宽度求行平均，花岗岩斑点被平均掉，而同向磨料纹保留为相邻行均值波动。
- **反光特征**：统计高亮度、低局部方差、低饱和度的平滑镜面像素，并结合平均亮度和 P90 亮度；明亮但边缘尖锐的石英斑因局部方差高被排除。
- **圆周连续性**：对 36 段曲线做轻量圆环平滑，降低单张虚焦/曝光误差。
- **崩口独立检测**：在上下边缘条带统计暗像素连续游程，并用宽度/深度阈值与普通划痕区分；上下缘邻近检测会合并为双侧崩口。

特征到 0–1 粗糙度指数的校准系数来自合成真值拟合，集中在 `roughnessFromFeatures()`。

## 老师傅规则卡

规则固化在 `src/core/expert.ts`。目标粗糙度窗口为 `0.43–0.58`：

| 粗糙度/缺陷 | 建议 |
| --- | --- |
| `<0.16` 釉化、镜面 | 120# × 6，粗砂开刃 |
| `0.16–0.30` 磨平 | 180# × 5，重新造砂 |
| `0.30–0.43` 偏光滑 | 240# × 4 |
| `0.43–0.58` 均匀 | 400# × 2 保养 |
| 窗口内但段内严重不均 | 240# × 4 后 400# × 2 |
| `0.58–0.70` 偏糙 | 400# × 4 |
| `0.70–0.85` 粗糙 | 600# × 4 |
| `≥0.85` 深划痕 | 400# × 5 找平，再 800# × 2 收光 |
| 边缘崩口 | 180# × 3–4 修形过渡，再 400# × 2 |

## 验证结果

`npm run validate:synthetic` 用同一套纯 TS 核心跑 6 组种子，每组都生成 CW/CCW 各 40 张并完整拼接、分析。当前结果：

- CW/CCW 曲线 Pearson 相关平均 **≈0.983**；
- 两方向平均绝对粗糙度差 **≈0.027**；
- 崩口召回 **100%**；
- 单套 40 张在 Node 验证中约 **0.4–0.5 s**，浏览器 Worker 冒烟约亚秒到 1 秒级，远低于 2 分钟；
- “现场工艺一致率” **≈87%**：定义为砂纸号相同或相邻一号、遍数差 ≤1；
- 严格“同号且同遍数”一致率 **≈66%**。这个数字在界面和验证输出中也如实展示，避免把容差一致误报成严格相同。

如果后续拿到真实器材员施工记录，应把 `src/core/expert.ts` 的规则阈值和 `roughnessFromFeatures()` 校准系数替换为真实样本拟合结果；页面的“严格/现场口径”双指标可继续用于回归验证。

```text
  core/analysis.ts          纹理抑制、反光、划痕、崩口、36 段曲线
  core/expert.ts            老师傅规则与砂纸建议
  core/alignment.ts         CW/CCW 圆环配准
  core/pipeline.ts          stitch + analysis + prescription
  workers/                  Vite Web Worker 与客户端
  state/                    store、localStorage 报告、历史基线
  ui/                       四个页面与 Canvas 图表/圆环/长带渲染
scripts/
  validate-synthetic.ts     真值验证门槛
  browser-smoke.mjs         Puppeteer/Edge 端到端冒烟
```

## 备注

- 真实照片导入目前会统一居中裁剪到 320×240；若照片分辨率/焦距差异很大，最好在拍摄引导中固定机位和焦段，或扩展 `filesToRawImages()` 保留原图比例与相机标定。
- 物理毫米数来自演示标定 `MM_PER_PX = 0.12`；真实使用前应用卡尺测量运行带宽度和周长后在 `src/config.ts` 校准。
