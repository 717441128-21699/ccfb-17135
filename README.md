# 冰壶运行带视觉检测与粗糙度分析系统

把冰壶翻转后，围绕运行带拍摄约 40 张重叠微距照片，系统完成：

1. **拍摄引导**：AR 对位环、每 9° 一个拍摄点、顺向/逆向两套、缩略图回览。
2. **环形拼接**：重叠区高通 + NCC 位移匹配、闭合校正、曝光增益链、暗角校正、羽化融合，极坐标映射成整圈圆环。
3. **运行带展开**：极坐标反变换展开为环向长带，照片间亮度增益拉齐、分块对焦评分驱动自适应 Unsharp；按反光模板 + 细划痕方向能量计算 36 段粗糙度，画整圈曲线并标崩口。
4. **磨损对比**：本次曲线 vs 上一次检查、Δ 变化、36 段砂纸号/遍数建议、崩口清单、正/反两套曲线一致性、合成真值自检与基准指标。

**拼接与粗糙度计算都在 Web Worker 中执行**，UI 不卡顿；展开长带与曲线绘制在 Canvas 上。全部 TypeScript 编写。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5188
npm run build      # tsc 类型检查 + vite 打包
npm run preview
```

## 命令行验收（无需浏览器）

```bash
npm run validate          # 8 只壶 × 顺/反两套，输出一致率/曲线相关/崩口/耗时
SEEDS=4 npx tsx scripts/validate.ts   # 更快的抽检
```

验收脚本直接调用与前端相同的核心算法（Node 中运行纯 TS 核心层），并把最近一次基准结果写入
`src/generated/benchmark.ts`，展示在“磨损对比”页。判定阈值：

- 36 段砂纸建议与“老师傅规则（套在真值粗糙度上）”一致率 ≥ 80%；
- 同一只壶顺向 / 逆向两套粗糙度曲线 Pearson 相关 ≥ 0.90；
- 40 张照片端到端平均耗时 < 120 s。

## 合成真值照片

`src/core/synth.ts` 在统一的“角度 × 径向”世界坐标中程序化生成：

- **5 种磨损程度**（镜面磨平 → 砂痕过粗）× **3 类花岗岩纹理**（细芝麻 / 粗黑白斑 / 云母片麻）；
- 黑白斑点、石英颗粒等**各向同性花岗岩纹理**（干扰项，用尺度分离与方向相干排除，不当成磨损）；
- 磨平处的**大面积柔光反射 + 窄镜面核心**，粗糙处的**环向细划痕**（密度随粗糙度增加）；
- 运行带内/外缘的**崩口缺口**（带真值位置、深度、宽度）；
- 每张照片独立的曝光增益、虚焦、暗角、传感器噪声与定位抖动；顺/反两套来自同一世界、独立拍摄参数。

## 目录

```
src/core/            纯 TS、不依赖 DOM/Worker 的算法层（Node 可直接验证）
  config.ts          36 段、几何/性能常量、老师傅五档砂纸规则表
  synth.ts           带真值的合成花岗岩/磨损/划痕/崩口/照片
  improc.ts          灰度、采样、高斯/盒模糊、Laplacian、NCC
  stitch.ts          NCC 匹配、闭合、曝光链、融合、极坐标圆环
  band.ts            运行带边缘检测、展开裁剪、亮度/对焦均化
  features.ts        径向反光模板、方向相干 + 水平延续划痕能量
  calibration.ts     五锚点校准、本壶量程自适应、环形中值、曲线插值
  chips.ts           两缘追踪 + 稳健基线残差的崩口检测
  analyze.ts         分析编排
  compare.ts         历次记录、环形相位对齐、对比
src/workers/         capture / stitch / analyze 三个 Worker
src/ui/canvas.ts     长带、粗糙度曲线、圆环叠加层 Canvas 绘制
src/main.ts          四个页面与 Worker 编排
scripts/validate.ts  命令行验收 + 基准回填
scripts/dump.ts      导出 diag/*.png 便于肉眼检查中间产物
```

## 判定口径说明

“老师傅做法”由 `ADVICE_TABLE` 五档规则刻画（60#×5 / 100#×4 / 150#×3 / 240#×2 / 320#×1）。
验收同时统计估计档位与真值磨损等级、以及与“真值连续粗糙度套用同一规则”的一致率；后者才是
老师傅在该真值下会给出的实际建议。相邻档误差主要来自片区边界的部分容积效应。
